# 🏥 Clínica Souza — Site Institucional

Site institucional fictício de uma clínica de saúde, desenvolvido como trabalho acadêmico. O projeto foi construído inteiramente em **HTML5** e **CSS3**, sem frameworks e sem back-end.

## 📋 Sobre o projeto

A Clínica Souza é uma clínica de saúde fictícia criada para fins de estudo. O site apresenta a identidade visual da clínica, os serviços oferecidos, a equipe médica e um canal de contato, em um layout limpo com paleta de tons de azul.

## ✅ Requisitos atendidos

- [x] Navbar com logo, menu de navegação e barra de pesquisa
- [x] Mínimo de 2 imagens de serviços *(3 imagens utilizadas)*
- [x] Descrição textual de cada serviço oferecido
- [x] Equipe fictícia com 3 membros, cada um com foto e cargo
- [x] Formulário estático de contato — Nome, E-mail, Cidade e Estado (sem processamento após o envio)
- [x] Uso de pelo menos 2 níveis de cabeçalho (`<h1>` e `<h2>`)
- [x] Rodapé com informações institucionais, links rápidos e redes sociais

## 🛠️ Tecnologias utilizadas

- **HTML5** semântico (`header`, `main`, `section`, `footer`)
- **CSS3** com *nesting* nativo para organização dos seletores
- [Font Awesome 6.5.1](https://fontawesome.com/) — ícones
- [Google Fonts — Poppins](https://fonts.google.com/specimen/Poppins) — tipografia

## 🧩 Seções do site

| Seção      | Descrição                                                      |
|------------|-----------------------------------------------------------------|
| Navbar     | Logo, menu (Home, Serviços, Equipe, Contato) e barra de busca   |
| Serviços   | 3 cards com imagem, título e descrição de cada serviço          |
| Equipe     | 3 profissionais fictícios com foto, nome e cargo                |
| Contato    | Formulário estático (Nome, E-mail, Cidade, Estado)              |
| Rodapé     | Sobre a clínica, links rápidos, contato e redes sociais         |

## ▶️ Como visualizar o projeto

1. Baixe ou clone este repositório
2. Abra o arquivo `index.html` em qualquer navegador

Não é necessário instalar nada — o projeto é 100% estático.
